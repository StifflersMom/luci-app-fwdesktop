luci-app-fwdesktop package feed

Signed apk feed for OpenWrt 25.12 (the package is architecture independent). Source and documentation: github.com/StifflersMom/luci-app-fwdesktop.

One time setup on the router

wget -O /etc/apk/keys/fwdesktop-feed.pem https://stifflersmom.github.io/luci-app-fwdesktop/fwdesktop-feed.pem
echo "https://stifflersmom.github.io/luci-app-fwdesktop/packages.adb" >> /etc/apk/repositories.d/customfeeds.list

Install and update

apk update
apk add luci-app-fwdesktop      # install
apk upgrade luci-app-fwdesktop  # later updates
